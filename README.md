# Webhook Chant Portfolio

Premium static portfolio website for showcasing the NOIR, Ember Kitchen and PrimeFix demo projects.

## Files
- `index.html` — portfolio page
- `css/style.css` — responsive styling
- `js/script.js` — reveal animations
- `README.md` — setup notes

## Deploy with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the **contents** of this folder, not the ZIP.
3. Ensure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Source: **Deploy from a branch**.
6. Branch: `main`; folder: `/ (root)`.
7. Save and wait for deployment.

## Important
Before publishing, replace `YOUR-BUSINESS-EMAIL@gmail.com` in `index.html` with the business Gmail you want prospects to contact.
